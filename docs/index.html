MarkdownLLM

Records your agent keeps in markdown and git, where nothing a later session relies on changes silently. A workspace is a folder of typed markdown records in its own git repository; a checker runs at every commit and refuses broken structure; and a change to something other records rely on cannot land until the agent has worked through what depends on it and you have ruled on what it may not settle.

Start here: The First Hour — install, create a workspace, run one whole session. Keep the Glossary open for the framework's words; read Limitations first if you are deciding whether to use it at all.

These pages are written for people. The specifications are written for the agent and live in the repository; this site is published from docs/ at the same commit.
