# A Floor Rule Reads The Need It Forbids As A Slip

## The Insight

When the floor enforces a rule, every act the rule forbids reads, in the
record, as a mistake by whoever did it — and the agent that reads the
record will say so. The ticket protocol said one writer per turn, and the
floor made it true: a second write at the same status rang nobody. A
deferral was recorded with it: a content-change wake is answered *no*
until a live run shows the need. Five weeks later a seat wrote on a ticket
it did not hold, carrying the one fact the holder was waiting for, and
nothing rang. The agent reading the record found the rule, found the
write that broke it, found two earlier writes that had broken it without
consequence, and concluded: a protocol slip; make the slip loud; close
the deferral as *no*. The operator read the same record and said: that is
the need. "There needs to be an interrupt."

Both readings were consistent with the evidence. The difference is where
the rule sits. From inside the rule set, the write is an error against the
rule. From outside it, the rule is an error against the write — the seat
had something to say and the protocol gave it no way to say it, so it
said it anyway, three times. A rule that people keep breaking in the same
direction is being told something.

## Why It Matters

The floor's great virtue is that it makes rules true rather than asked.
That virtue has a shadow: once a rule is enforced, the record of its
violations stops looking like demand and starts looking like error, and
the agent's first diagnosis will be the one that keeps the rule. A
deferral of the form "no, until the record shows the need" is only
honest if the reading of the record is not done by the rule's defender.
This is the belief-revision version of the standing truth: the agent can
reason about the consequence, and the ruling on what it means stays with
the operator.

## How To Apply

- When a deferral names the evidence that would overturn it and that
  evidence arrives, put the question to the operator *as* the overturning
  case, not as a slip to be corrected — state both readings and which the
  agent prefers, and let the ruling land.
- Count the repeats. A violation that recurs in one direction with no
  consequence is the strongest form of the evidence a deferral was
  waiting for; the agent's reading of it as "harmless, nobody noticed" is
  the tell.
- When the ruling goes against the agent's reading, record the agent's
  reading too, in one line. The next deferral is read by a session that
  will have the same bias.
