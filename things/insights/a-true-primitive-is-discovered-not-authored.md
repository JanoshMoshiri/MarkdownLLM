# A true framework primitive is discovered, not authored

## The Insight

A genuine primitive is not a creation; it is a **realisation of something already in front of
you that you never named.** The framework's role at its constitutional layer is not to *write*
the laws of how model-of-reality systems behave — it is to **discover** them, articulate them in
words and syntax, and share them so someone else can see them too. Discovery is only the first
half; the work is the second — making a private knowing transmissible.

This yields a sharp, reusable test for what belongs in the manifesto/kernel:

1. **Truth precedes naming.** Ask: *was this already true before anyone named it?* If naming it
   changes what the existing mechanisms *do*, it is an invention — a bolt-on, reject it. If
   naming it only changes what we can *see* — revealing a spine the mechanisms already
   implemented — it is a discovery. Enshrine it as a recognition, adding **zero new mechanism**.
2. **The status was right all along.** A corollary observed live this session: when the
   divergence primitive was named, the specs it unified kept their `stable` status untouched —
   correctly, because they were stable *because the truth they implement was true from the
   beginning*, before we named it. Naming is **epistemic, not ontological**: it changes our
   sight, not the thing. An apparent "the label changed because the file changed" divergence
   dissolves on inspection — the bytes moved, the contract did not.

## The Self-Ratifying Test

A true primitive has a fractal signature: **its own introduction must obey it.** If promoting a
candidate requires *violating* it, that disproves the candidate in the act of asserting it. The
divergence primitive was enshrined via route 2 of *its own* taxonomy (revise the model, with
recorded rationale, through the framework's own change process — never a sideways bolt-on); the
decision *not* to disturb the `stable` labels obeyed it too. A rule that only holds while you
are looking at it is one you invented; a rule that holds **whether or not you name it, pin it,
or notice it** is one you discovered. That invariance — not conviction, not elegance — is the
evidence.

## Why It Matters

This is the razor against the most dangerous failure mode of an expansive moment: bolting a
clever new layer onto the constitution because it *feels* profound. Restraint is not timidity
here — it is fidelity to the discovery stance. Prefer naming and unifying existing mechanisms
over adding new ones; keep the limbs, name the spine; and let a candidate **earn** manifesto
status by *recurring with evidence*, not by the force of the session that surfaced it. This
insight applies that bar to itself: it is captured as an active insight, **not** enshrined in
the manifesto today — held to see whether it reappears across domains and sessions, exactly the
test the divergence primitive had to pass first.
