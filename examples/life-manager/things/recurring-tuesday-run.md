# Tuesday Evening Run

## What Happens

Every Tuesday after work: 30–40 minutes, route along the canal, distance grows
by roughly half a kilometre a week while it stays comfortable.

## Why It Recurs

Training for `goal-run-a-10k` lives or dies on consistency, not on any single
run. A recurring thing carries the habit; the goal carries the outcome. When
this lapses for two consecutive weeks, that is a signal to surface at the
weekly review — not a reason to silently delete the thing.

## Current State

Held for two weeks running. The second run of each week (weekend, unscheduled)
is deliberately not tracked — only the anchor run earns a thing.
