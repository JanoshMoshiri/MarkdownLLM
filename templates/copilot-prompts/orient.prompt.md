Run **orient** for this domain — the session-start ritual in full, then the
judgement half that no hook performs. Invoked deliberately: the startup hook's
channel carries the digest but defers the kernel, and a read the entry file
merely *instructs* is economised
(`emitted-content-is-read-instructed-content-is-economised`); this prompt is
the pull.

1. **Emit, then read end to end:** run
   `python {framework_root}/tools/mdllm.py session-start .` (or
   `sh {framework_root}/tools/mdllm.sh session-start .`, which selects an
   interpreter that can import PyYAML the way the hooks do). Receipt first:
   the kernel block ends with its `[kernel emitted whole — …]` trailer and the
   digest carries no `[truncated]` marker. If either fails, say so and read the
   named file in full before continuing — a block that did not land whole is
   not loaded.
2. **The walk** — the four steps the digest cannot perform
   (`{framework_root}/templates/prompts/`; a scaffolded domain carries the same
   four under its own `prompts/`):
   - `session-orientation` — what changed since you were last here (`git log`
     since the last `session-end:` commit), and the scoped staleness check:
     live insights × changed things, never a sweep.
   - `domain-velocity` — the residue behind the digest's trend line: churn
     without progress, unblocks nobody took, what each stall *means*.
   - `evaluate-triggers` — judge the triggers the floor could not evaluate; the
     digest's fired set is already the floor's.
   - `surface-attention` — order what the above produced; the digest's
     reconciliation cues, reckoning line and seat line are inputs, not outputs.
3. **Tell the operator where things stand**, in their words, leading with what
   matters and omitting what is fine. Consume the digest's figures; never
   recompute them. If the operator opened with a specific request, this walk is
   background to it — answer the request first.
